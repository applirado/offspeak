# Security

OffSpeak promises that audio, transcripts and settings never leave your PC. If you find a way around
that promise, or any other security problem, please tell us privately: use
[Report a vulnerability](https://github.com/applirado/offspeak/security/advisories/new) on GitHub
instead of opening a public issue.

Examples of what we would like to hear about:

- a connection that the built-in network guard lets through after setup
- dictated text, audio or clipboard content ending up somewhere other than `%LOCALAPPDATA%\Offspeak`
- a way to make the installer or setup run code that is not OffSpeak's

We answer as soon as we can and fix confirmed problems in the next release. Only the latest release
is supported.
